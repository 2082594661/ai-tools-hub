颜色转换

输入 HEX、RGB 或 HSL 任意一种，自动换算出另外两种，附实时色块预览，点「复制」即用。

怎么用： ① 在左侧彩色方块里按住拖动选色，拖下方彩虹条换色相； ② 也可直接在输入框填 #ff6b6b 或 rgb(255,107,107)； ③ 点下方「热门颜色」一键套用； ④ 点 HEX / RGB / HSL 后的「复制」即可拿走。
🎯 拖动方块选色（左右=饱和度，上下=明暗）
🌈 拖动彩虹条换色相（红→黄→绿→青→蓝→紫）

🔥 热门颜色

点一下色块，立即应用到上方取色器，HEX / RGB / HSL 数值同步更新
