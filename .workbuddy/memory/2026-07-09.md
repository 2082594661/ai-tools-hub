## 修复图片显示问题（根因：SVG 内容损坏 + 兼容性）
- 用户截图反馈首页卡片"有的有图有的裂图"（第二张 Copilot 卡片显示 alt 文本）。
- **真因**：`ai-code-assistant-vs-github-copilot-alternative.svg` 的 emoji `<text>` 字段为空且 XML 格式非法（多了一个 `>` → `></>`），浏览器解析崩溃导致整张图不渲染。之前审计脚本正则没捕获异常格式，误报为"0 问题"。
- **修复方案**：
  1. 用 Pillow (msyh.ttc 字体) 重新生成全部 **27 张 PNG 横幅**（渐变背景 + 白色卡片 + emoji + 分类标签），替代有问题的 SVG。
  2. 全站 40 个 HTML 文件的 142 处 `banners/*.svg` 引用批量替换为 `.png`。
  3. 补漏生成缺失的 `free-ai-video-editor-no-watermark.png`。
- 复验：142 张 banner img 全部指向存在的 PNG、0 个 SVG 残留、审计 **TOTAL ISSUES: 0**。
- PNG 比 SVG 更可靠：任何浏览器/平台/file:// 都能正确渲染，不存在 SVG 解析兼容性问题。
