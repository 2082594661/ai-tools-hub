## 小工具实现说明（重要，避免误述）
- 现 3 工具均 **纯前端、零 API、浏览器本地运行**：① 二维码生成（手写 qrcode.js，GF256+RS 校验）② 图片智能压缩（canvas→WebP，省 60–90%）③ 艺术字（canvas 渐变/描边/阴影/霓虹）。
- 之前移除的 4 个：标题/文案生成器=模板非真 AI（可复活但流量一般）；TTS 可用浏览器 `SpeechSynthesis`（免费、零 API）复活为引流工具；STT 依赖 Web Speech API（仅 Chrome 支持，免费）。
- 真 AI 类（图片去背景/老照片修复/文生图）需服务端 API（国内硅基流动/智谱/通义，便宜），需用户拍板是否接受 API 成本 + serverless 部署；浏览器端 ML 模型（@imgly/background-removal）可做去背景但包体数 MB、首屏慢。

## 我对盈利概率的判断（给用户的诚实评估）
- 单靠展示广告盈利概率偏低（AI工具站赛道极饱和、新站百度沙盒期长、CPM modest）
- 更高杠杆路径：联盟营销/CPS（工具推荐返佣）> 展示广告；配合抖音导流
- 小工具带来留存+复访，是比纯评测站更优的承接/变现载体
